https://davionnic.github.io/empty-but-live/

## Three options considered

1. **GitHub Pages (chosen)** — free static hosting from this repo. Fits a near-blank page. Zero monthly cost. I already use GitHub daily.
2. **Netlify Drop** — also free and fast for drag-drop HTML, but another account/dashboard to keep alive for a page that only shows my name.
3. **Vercel** — free and solid for later Next.js, but heavier than needed for a blank `index.html` today.

## Why this stack
I need a reachable HTTPS URL now, not a CMS. GitHub Pages is free, matches “empty/near-blank,” and I can maintain it by editing one file in this repo.

## Can I maintain this?
Yes — one `index.html`, Pages from `main` / root. No build step.

## Backend?
Not yet. This page has no API. Backend skill shows up in separate repos (Task CRUD API, ACRA).
