# Prompt Ladder Brief

**Dave Andrei Almia Gallo · Backend AI Engineer @ FlyRank · Week 2**

## Why it matters

The gap between a lazy prompt and an engineered one is the cheapest performance upgrade in AI, and most people never see it because they change five things at once and learn nothing. This assignment forces the discipline: one change at a time, output compared at every step. By the end you won't just have a better prompt, you'll know exactly which ingredient earned its place.

## The task

Start with a genuinely weak prompt from your own track. Improve it across five versions — exactly one layer per version. Run every version, compare outputs, write four notes each time. Finish with a final reusable prompt a stranger on your track could use.

## Deliverable

A prompt ladder document: weak baseline + five versions, output (or excerpt) for each, four notes per version, final reusable prompt.

## Pass / revise

- Six runs total; each version = one named layer
- Notes describe output changes, not only prompt changes
- At least one honest "didn't help / made it worse"
- Final prompt works for a stranger
